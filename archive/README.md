# Historical group coursework archive

These notebooks and scripts are copies of the original uploaded group assignment files, renamed for readability. They preserve the original hard-coded operating-system paths and use dependencies/files not included in this package. Some analysis and machine-learning assumptions may be problematic. **They are provided as historical source material and are not the reproducible entry point.**

To run the supported portfolio analysis, start with [`../src/ipl_analysis.py`](../src/ipl_analysis.py). For missing inputs and methodological caveats, see [`../docs/DATA_NOTES.md`](../docs/DATA_NOTES.md).
